### 주요 단어 (Key Terms)

- **서버 (server)**: 요청(request)을 받고, 그에 맞는 데이터나 서비스를 건네주는(response) 역할
- **베어메탈 (bare metal)**: PC 한 대에 OS 설치 후 여러 소프트웨어 운영
- **하이퍼바이저 (hypervisor)**: PC 한 대에 여러 가상 머신
- **컨테이너 (container)**: PC 한 대에 여러 컨테이너
- **가상화 (virtualization)**: 실제 서버가 존재하지 않더라도 마치 있는 것처럼 만드는 기술
