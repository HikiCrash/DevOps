### 주요 코드 (Key Code)

- **`#!` (셔뱅 shebang)**

  어떤 인터프리터로 실행할지 OS에 알려주는 부분으로 파일의 첫 줄에 작성한다.

  > "이 파일을 실행할 때, 바로 뒤에 적힌 프로그램으로 이 파일을 해석하라."

- **`#!/bin/bash`**

  이 파일은 Bash 문법이니, Bash로 실행하라.

- **`cd "$(dirname "$0")" || exit 1`**

  해당 스크립트가 있는 디렉터리로 이동하고, 이동 실패 시 스크립트 종료

  - **`$0`**: 현재 실행한 스크립트의 이름 또는 경로
  - **`"$0"`**: 스크립트 경로에 공백이 있을 수 있기 때문에 따옴표 사용
  - **`dirname`**: 파일 경로에서 파일 이름 빼고 디렉터리 부분만 출력하는 명령어

- **`./command.sh qwen3:0.6b 8000`**

  - `./command.sh` - 첫번 째 인자($0)
  - `qwen3:0.6b` - 2번째 인자($1)
  - `8000` - 3번째 인자($2)

- **`$( ... )` (명령어 치환, command substitution)**

  괄호 안의 명령어를 실행하고 그 명령의 표준 출력을 이 자리에 넣기

  - **예시**: `echo "$(pwd)"`
  - **결과**: `pwd` 와 같음

- **`exit`**

  리눅스 명령어는 성공 또는 실패 값을 남김
  - 성공: `0`
  - 실패: `0 이외`

- **`||`**

  앞 명령이 실패하면 뒤 명령을 실행한다.

- **`|| exit 1`**

  앞 명령이 실패할 경우 종료를 하되, '실패'를 의미하는 상태코드 1을 남김
